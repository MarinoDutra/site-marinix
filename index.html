InCode

A landing page e o sistema de inscrições do InCode: a pessoa se inscreve, envia a declaração em PDF, paga pelo Mercado Pago e a equipe acompanha tudo num só lugar.

  1. 01 Inscrição Formulário salva os dados direto no MySQL.
  2. 02 Declaração Upload do PDF de até 5 MB, guardado no banco e nunca público.
  3. 03 Pagamento Checkout no Mercado Pago, confirmado por webhook assinado.
  4. 04 Acompanhamento Downloads por links assinados que expiram em 7 dias.

O que fizemos

Saímos do Supabase

Migramos inscrições e arquivos para um MySQL próprio usando Prisma. O projeto deixou de depender de um serviço externo e passou a rodar inteiro na nossa infraestrutura.

Migrations que funcionam do zero

A primeira migration registra a estrutura antiga de inscrições; a segunda adapta os campos e cria o armazenamento de declarações. Funciona tanto num banco vazio quanto no banco que já estava em produção.

Arquivos privados de verdade

Os PDFs ficam no banco e só saem por links assinados com uma chave secreta, válidos por sete dias. Credenciais nunca vão para o front-end.

Deploy com Docker

O Docker Compose se conecta ao MySQL que já existia no servidor, sem criar outro banco. As migrations rodam antes de liberar o tráfego, e testes e build validam cada versão.
